# Agent Reliability Kit v0.1.0 — Alpha

Agent Reliability Kit (ARK) is a local-first Python toolkit for inspecting recorded AI-agent workflows and enforcing explicit policy contracts in CI. This is the prepared first alpha release candidate of the public project. The draft release workflow creates the tag and attached build artifacts from a fully verified commit. It is intentionally labelled **pre-release / alpha**: validate it against synthetic traces and your own workflow before relying on it.

## Included

- JSONL trace recording and schema-validated loading with source and line-specific errors.
- CLI commands: `ark inspect`, `ark diff`, `ark evaluate`, and `ark policy`.
- Declarative JSON policies for allowed, required, and forbidden events; event and call limits; total and per-event duration/token budgets.
- Behavioral trace diffs with dotted ignore paths and optional nested added/removed/changed field paths.
- JUnit XML output from evaluation and policy checks for CI reporting.
- Reusable composite GitHub Action that fails a consuming workflow when its recorded trace violates a policy.
- Best-effort recursive key redaction, a synthetic customer-support workflow, and a duplicate-refund regression demo with an explicit failing policy case; see the [CI integration guide](https://github.com/Hariharans1971/Agent-Reliability-Kit-ARK-/blob/main/docs/CI_INTEGRATION.md). Includes tests, security/contribution guidance, and weekly Dependabot updates.
- Single-file offline JSONL viewer: [Try the demo](https://portfolio1-tau-sandy.vercel.app/ark-trace-viewer.html).
- Visual workflow architecture and practical CLI/integration guides.

## Use the GitHub Action

```yaml
- name: Enforce agent execution policy
  uses: Hariharans1971/Agent-Reliability-Kit-ARK-@v0.1.0
  with:
    trace: artifacts/agent-trace.jsonl
    policy: policies/agent-policy.json
    python-version: "3.12"
```

The consuming repository must create or collect the trace before this step. The trace and policy paths are resolved from the consuming repository's workspace. For stricter supply-chain control, review the release commit and pin the action to its full commit SHA.

## Install the Python package

Download the wheel asset attached to this release and install it with:

```bash
python -m pip install ./agent_reliability_kit-0.1.0-py3-none-any.whl
ark --help
```

The package requires Python 3.10 or newer and has no mandatory runtime dependencies. Use the exact wheel filename shown in the release assets.

## Validation included

- Unit tests across Python 3.10, 3.11, and 3.12.
- Ruff correctness/static-analysis checks.
- Source distribution and wheel build, followed by installation into a clean virtual environment.
- Passing and expected-rejection examples for the composite GitHub Action.
- Release assets include source/wheel distributions and `SHA256SUMS`.

## Known limitations

- ARK evaluates only the events and metrics captured by instrumentation; incomplete traces can hide behavior.
- Positional trace diffing does not semantically align reordered events.
- Redaction is best-effort and does not guarantee anonymity or detect every secret inside arbitrary strings.
- ARK is a developer tool, not an agent runtime, formal verification system, or safety guarantee.
- The project is still early-stage. Review [architecture and limitations](https://github.com/Hariharans1971/Agent-Reliability-Kit-ARK-/blob/main/docs/ARCHITECTURE.md) and [security guidance](https://github.com/Hariharans1971/Agent-Reliability-Kit-ARK-/blob/main/SECURITY.md) before using real data.

Please report reproducible issues with synthetic traces and include Python/ARK versions. Do not submit production prompts, customer data, credentials, or API keys.
