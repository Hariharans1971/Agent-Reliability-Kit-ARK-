# Code of Conduct

We aim to make participation in Agent Reliability Kit respectful and harassment-free for everyone.

Be considerate, provide constructive feedback, critique ideas rather than people, and welcome contributors with different experience levels.

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, and publishing private information without permission. Maintainers may remove contributions or interactions that violate these standards. Report concerns privately to the repository owner through GitHub.
